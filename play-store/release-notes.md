# Release Notes — v99 (1.0.0)

Copy into the release notes box (Production → Create new release) when uploading the AAB. Release name: `1.0.0 (v99)`

---

**What's new in v99**

New — Interactive tutorial walkthrough (replay anytime from Settings → Replay Tutorial):
- 4 chapters: Setup → Read & Navigate → Annotate → Review & Sync
- Hands-on steps: add a student, open the mushaf, mark a mistake (red highlight), verse menu, notes & voice notes, draw on the page with pen/laser/erase, set the Daily Recitation reading mark (ribbon), share a page, and sync
- Practice student is created during the walkthrough and removed automatically when it ends
- Stable bottom sheet, spotlight ring, and guided hand — blocked zones stay inert so you only tap what the step asks for

Improvements:
- Landscape split-view fit relief and tablet drawing toolbar polish
- Sync wording clarified: everything saves on device first, then syncs automatically (open / foreground / 30 min) — tap Sync (n) to sync now
- One reading mark per student — setting a new mark replaces the old one
- Night mode, translation and split-view controls remain in Settings

Fixes: tutorial anchor wiring, blocked-zone overlay, Back navigation during the walkthrough, and practice-student lifecycle.

As always: multi-student profiles, bookmarks/notes/highlights/drawings/mistakes sync across devices, word/verse playback with multiple reciters, and no ads or tracking.

**Full description (for reference — not the changelog):**
Read the mushaf in authentic page mode with multiple Arabic fonts, or switch to continuous and verse-by-verse modes. Track each student separately, share annotated pages, and review mistakes before the next lesson.
