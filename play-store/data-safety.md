# Data Safety Form — Answers

These are the answers for the Play Console **App content → Data safety** questionnaire,
based on what Teach Quran actually does.

## Data collected

| Data type | Collected? | Shared? | Purpose | Optional? |
|-----------|-----------|---------|---------|-----------|
| Email address | Yes | No | Account (username becomes an email-style identifier) | No |
| User IDs | Yes | No | Account identity, student profiles | No |
| Name (students) | Yes | No | Student profiles created by parent/teacher | No |
| User-generated content (bookmarks, notes, highlights, drawings, reading marks) | Yes | No | Syncs across the user's own devices | No |
| Audio files (voice notes) | Yes — device only | No | Local recording; NOT uploaded | Yes |
| Photos, contacts, location, device IDs, purchase history, health/fitness | No | — | — | — |

## Data sharing
- **Nothing is shared with third parties** (no analytics, no ads SDKs, no device IDs).

## Key answers in the form

1. **Is this app encrypted in transit?** → Yes (all sync/account traffic goes over HTTPS to Google Firebase).
2. **Can users request data deletion?** → Yes — delete a student profile from the student list, or contact us for full account deletion.
3. **Data collected in the past 24 hours on this app** → Select the rows from the table above (email, user IDs, names, user content).
4. **Data types that are optional or can be turned off** → Voice notes are device-local and removable; highlights/notes can be deleted per verse.
5. **How data is used** → App functionality (sync, account, progress tracking). No advertising or personalization.
6. **Ads** → The app contains **no ads** → No.
