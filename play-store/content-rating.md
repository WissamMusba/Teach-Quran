# Content Rating — Questionnaire Guidance

The app is an educational Quran reader — the rating should land on **Everyone**.

| Question | Answer |
|----------|--------|
| Violence | None |
| Sexuality / sexual content | None |
| Profanity / vulgar language | None |
| Alcohol, tobacco, drugs | None |
| Gambling | None |
| Hate speech / discrimination | None |
| User interaction | Note: users can add notes/highlights, but there is **no public/social interaction** between users — content is private to the account. Select the least restrictive appropriate option (no interaction). |
| Sharing location | Not shared |
| Digital purchases | None (app is free, no IAP) |
| Advertisements | None |

Expected result: **Everyone** (all age groups).
